关于我们

AIEC（AI Engineering Club）是一个以工程实践驱动的 AI 技术社团。我们不教你怎么在网页上跟 AI 聊天，我们教你怎么写 API、构建 Agent、部署模型、做内网穿透——从第一行代码到上线跑起来，全程自己搞定。

采用 PBL（项目驱动）模式。每次活动，你带着电脑来，带着一个能跑的项目走。学期末，你收获的不是一张证书，而是一份可以写进作品集的真实项目。

我们教什么

  • API 调用与多模型编排（OpenAI / Anthropic / DeepSeek）
  • Agent 构建与工具调用（Tool Calling）
  • Linux 运维与服务器部署
  • 内网穿透与云端上线
  • 提示词工程与上下文管理

项目展示

QuizAuto
AI 自动批改机。调用千问 OCR 和 LLM，实现单词小考的自动识别与语义级批改。老师再也不用熬夜改卷子。
Forge
高性能 Agent 引擎。因为受不了现有 Agent 框架的启动速度，我们用 Go 语言从零重写了整个引擎，冷启动从数秒压到毫秒级。
BusinessSimulation
商赛沙盘系统。与商科社团联名开发，基于 Spring 架构，集成内网穿透技术。让参赛者第一次拥有不被黑箱垄断的沙盘工具。
